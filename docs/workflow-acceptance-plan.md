# Workflow 产品验收清单

每条用例单独记录实际结果、环境、断言、证据与缺陷编号。状态使用「待测 / 通过 / 失败 / 阻塞 / 不适用」。本清单的初始状态全部为待测。自动化合成模型用于可重复的控制流验证；实际模型联调用独立结果记录。Web 与 Electron 分别记录，单元测试结果不能替代界面验收。

## 验收环境与证据

- 使用隔离的数据目录、合成项目、合成文档和测试模型配置。
- 记录插件提交、bundle 固定提交、Desktop 与 Harness 版本、操作系统和窗口尺寸。
- 每项记录前置状态、操作、预期、实际、耗时和证据路径；失败保留现场并关联回归用例。
- 截图覆盖浅色、深色、系统主题、窄窗口、长内容、并行步骤、调试暂停、步骤会话和文件变更。
- GIF 从真实交互录制生成；发布前逐帧检查可识别信息和凭证。
- 语义依赖：运行中消息送达方式、补聊输出采用方式、文件应用策略、分支单步范围、页面关闭行为由产品约定确定。
