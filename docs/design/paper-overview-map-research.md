# 论文全景导图：结构与视觉依据

## 目标

读者在阅读正文之前，先回答四个问题：论文要解决什么、作者的总体答案是什么、每条关键机制为什么成立、实验在什么条件下支持结论。导图是文章的导航与论证摘要，具体推导和图表解读仍在正文。

## 调研结论

- [IHMC 的概念图方法](https://cmap.ihmc.us/docs/theory-of-concept-maps)要求先确定聚焦问题，以连接词构成有意义的命题，并让概念从整体走向细节。交叉连接只保留能解释不同分支关系的部分；卡片中堆满完整段落会掩盖结构。
- [Xmind 的结构指南](https://xmind.com/user-guide/structure-new)把中心主题、主分支和子主题分为不同层级。论文导图因此需要一个显著的中心答案，再把预填、解码与运行条件等机制放在同一层级；每个分支内部再显示障碍、洞察和做法。
- [Miro 的概念图指南](https://miro.com/concept-map/how-to-make-a-concept-map/)强调关系本身的表达。论文解读适合在树状思维导图中加入“问题 → 答案 → 机制 → 证据”的论证方向，使连接线承载明确含义。
- [FreeToken 原论文](https://arxiv.org/html/2608.16157v1)同时讨论预填阶段的整层搬运与状态复用、解码阶段的专家缓存与带宽分工，以及随可用显存变化的运行时管理。导图的三个分支分别对应这三组问题，底部证据写明模型、机器、负载和原图位置。

## 交互与版式

纵向阅读顺序为问题、答案、三个机制分支、证据与边界。分支固定采用“障碍 / 洞察 / 做法”三行，避免只有名词而没有因果。图面仅保留论文主题、必要的关系标签和原文位置；标题、装饰性说明和重复信息不占用阅读空间。颜色只区分层级与阶段；边线使用轻微手绘质感，保持 Excalidraw 源文件可编辑。正文展示内嵌 SVG，中文以矢量字形固化，保证本地网页和公众号排版显示一致。

宽度按 760 px 设计，以适配现有文章栏；卡片正文源字号为 17 px，实际显示时按容器等比缩放。长英文术语只在词边界换行。整图随页面自然滚动，各卡片保持可独立扫读。无障碍描述保留完整问题、答案、机制、证据和边界。

## 生成检查

1. 聚焦问题必须指向论文具体障碍；核心答案必须能直接回应它。
2. 每个分支包含可核查的旧障碍、作者观察及具体机制；不同分支共同覆盖支撑主结论的阶段和实现。
3. 结果数字需带指标、机器、模型、负载、基线与原文图号；设计意图不得写成已测收益。
4. 边界同时说明原文已测条件与尚不能推出的推广。
5. 审阅时用原文覆盖表逐项核对导图，合并重复信息，检查每个可见标签是否承载新的信息，并检查 SVG 与 Excalidraw 文件的可读性。
