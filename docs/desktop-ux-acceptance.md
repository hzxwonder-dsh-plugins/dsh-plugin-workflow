日期：2026-09-21。范围：Desktop 工作流总览、编辑器、步骤设置、创建—运行—对话链路。被测版本为分发 bundle 中
`vendor/dsh-plugin-workflow` 的当前提交，在隔离的 fixture home 中通过真实 Desktop 窗口逐条执行。

[调研、设计取舍与界面约定](desktop-ux-research.md)

## 证据边界

本轮没有招募真实新用户，尚不能量化完成时间、学习成本或满意度的提升。最小化与恢复由窗口服务器处理，自动化通道
无法触发该按钮，真实最小化仍需人工核对一次。完整读屏软件测试、所有系统缩放档位、跨操作系统窗口生命周期不在本轮
已验证范围。对比度按 WCAG 2.1 判定，只代表可读性下限，不衡量层级感与留白。截图导览是静态界面序列，不代表实时
执行录像。隐私扫描为规则检查和图像人工检查，不构成绝对无泄漏保证。
