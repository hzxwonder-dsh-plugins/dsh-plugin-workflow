# 步骤设置与添加步骤验收

日期：2026-09-20。范围：Desktop 工作流插件的步骤设置、步骤材料入口和添加步骤弹窗。

## 交互约定

- 右栏标题固定，设置区域独立滚动；展开评审后仍可到达每轮会话、轮数、通过条件和高级设置。
- “添加步骤结果”将所选步骤输出映射为本步输入，并建立执行依赖。
- 添加步骤弹窗正文保留 18px 内边距，选项间隔 12px；窄屏使用单列。
- 新步骤可在说明中写“使用 subagents”与各角色职责，执行适配器提供 subagent 工具；子任务不能突破所属步骤工具权限。
- 已保存的结构化子代理配置仍由原调度器执行，保留论文评审的材料隔离和依赖顺序。该兼容路径尚未迁移成纯 prompt 配置。
